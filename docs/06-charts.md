# 차트 시스템

원문의 "외부 차트 라이브러리 없이 CSS 막대" 제약을 해제합니다.
대신 아무 차트나 그리지 않도록, **어떤 데이터에 어떤 폼을 쓰는지**와
**색을 무엇으로 정하는지**를 여기서 고정합니다.

색은 눈으로 고르지 않았습니다. 아래 모든 팔레트는
색각 이상 분리도(OKLab ΔE), 명도 대역, 채도 하한, 표면 대비를 계산해 통과시킨 값입니다.

---

## 1. 라이브러리

**Apache ECharts**를 씁니다.

| 이유 | 설명 |
|---|---|
| 히트맵·커스텀 시리즈 | 존 밀도 히트맵과 불릿·덤벨 차트를 커스텀 시리즈로 그릴 수 있음 |
| SVG 렌더러 | 최종 기획서 PDF에 **벡터로** 들어감. 확대해도 안 깨짐 |
| 서버사이드 렌더링 | PDF 내보내기를 서버에서 처리 가능 |
| 시간축 | 30분·1시간 버킷과 KST 표시를 기본 지원 |

**작은 지표는 라이브러리를 쓰지 않습니다.** 스파크라인, 진행 링, 미터,
스탯 타일은 CSS·인라인 SVG로 직접 그립니다. 축도 범례도 없는 그림에
차트 인스턴스를 띄우는 건 낭비고, 축제 당일 폴링 화면에서는 느립니다.

렌더러는 `svg`로 고정합니다. Canvas는 PDF 내보내기에서 래스터가 됩니다.

## 2. 팔레트

### 2.1 카테고리 (정체성)

시리즈가 **무엇인지** 구분할 때만 씁니다. 순서는 고정이며 절대 순환시키지 않습니다.
슬롯 순서 자체가 색각 안전 장치입니다 — 임의로 재배열하면 검증이 깨집니다.

| 슬롯 | 색 | Light | Dark |
|---|---|---|---|
| 1 | green (브랜드) | `#12855C` | `#2E9A6E` |
| 2 | amber | `#C98400` | `#C87A26` |
| 3 | violet (브랜드) | `#6A4BC4` | `#8B72D8` |
| 4 | red | `#D6403C` | `#D85F5A` |
| 5 | blue | `#1F6FD0` | `#4A88D8` |
| 6 | magenta | `#C4479B` | `#CB5FA4` |

검증 결과 (light 표면 `#FFFFFF` / dark 표면 `#1C201D`):

| 검사 | Light | Dark |
|---|---|---|
| 명도 대역 | 통과 | 통과 |
| 채도 하한 | 통과 | 통과 |
| 인접 CVD 분리 ΔE | 8.6 (목표 ≥8) | 8.1 |
| 정상시력 분리 ΔE | 21.9 (하한 ≥15) | 19.6 |
| 표면 대비 | 전부 ≥3:1 | 전부 ≥3:1 |

산점도·소규모 다중 차트처럼 **모든 쌍**이 동시에 보이는 폼에서는
**앞 3슬롯(green·amber·violet)까지만** 씁니다. 이 셋은 전체 쌍 검증도 통과합니다
(CVD ΔE 9.5 light / 8.1 dark). 4개 이상이 필요하면 나머지를 "기타"로 묶거나 분할합니다.

**7번째 시리즈는 없습니다.** 색을 새로 만들지 않고 "기타"로 접거나 소규모 다중으로 나눕니다.

### 2.2 상태 (예약됨)

여유·주의·집중은 **정체성이 아니라 상태**입니다. 카테고리 슬롯으로 절대 재사용하지 않고,
반대로 카테고리 시리즈에 상태색을 쓰지도 않습니다.

| 상태 | Light | Dark | 모양 |
|---|---|---|---|
| 여유 LOW | `#1B72A0` | `#4E9ECB` | 사각형 |
| 주의 CAUTION | `#BC8400` | `#BE8A22` | 삼각형 |
| 집중 HIGH | `#C22E44` | `#D9546A` | 세로 막대 |
| 데이터 부족 | `#858C83` | `#868D84` | 없음 |

전체 쌍 검증 통과 (CVD ΔE 12.6 light / 8.6 dark, 정상시력 20.0 / 16.9, 대비 전부 ≥3:1).

**상태는 색으로만 말하지 않습니다.** 모양과 한글 라벨이 항상 함께 갑니다.
직사광선 아래 폰 화면에서는 색 구분이 가장 먼저 무너지고,
색각 이상 사용자에게는 애초에 색이 신호가 아닙니다.
"데이터 부족"을 회색으로 둔 것도 의도입니다 — 판단할 수 없을 때 초록으로 칠하면
여유롭다는 거짓말이 됩니다.

### 2.3 순차 (크기)

혼잡 히트맵처럼 **연속적인 크기**를 나타낼 때 씁니다. 한 가지 색조, 밝은 곳 → 어두운 곳.

| | 1 (낮음) | 2 | 3 | 4 | 5 (높음) |
|---|---|---|---|---|---|
| Light | `#6BC29E` | `#3AA97D` | `#12855C` | `#0B6845` | `#084E34` |
| Dark | `#0D6A4A` | `#17936A` | `#3AB289` | `#6BC9A8` | `#9DDDC5` |

명도 단조 증가, 인접 단계 ΔL ≥ 0.06, 밝은 끝 표면 대비 2.14:1 light / 2.49:1 dark — 전부 통과.
**무지개 램프는 쓰지 않습니다.**

### 2.4 발산 (극성)

진단 점수 증감, 캠페인 전후 %p 변화처럼 **양쪽 방향**이 있는 값에 씁니다.

```
감소 ←  #1F6FD0 (blue)  ····  중립 #E6E8E2 / #333834  ····  #D6403C (red)  → 증가
```

중립점은 **회색**입니다. 여기에 색조를 넣으면 "변화 없음"이 "약간 뭔가 있음"으로 읽힙니다.
양쪽 팔의 단계 수를 같게 맞춥니다.

> 발산 축의 방향은 지표마다 다릅니다. 진단 점수는 증가가 좋고,
> 혼잡도는 증가가 나쁩니다. **파랑=좋음으로 고정하지 말고 축 라벨로 명시**합니다.

## 3. 화면별 차트

### 3.1 운영 대시보드

| 데이터 | 폼 | 색 | 비고 |
|---|---|---|---|
| 총 참여자 / 총 완료 / 최근 30분 | **스탯 타일** | 없음 | 숫자 하나에 차트를 붙이지 않음 |
| 시간대별 완료 | **영역 차트** (단일 시리즈) | 카테고리 1 | 끝점만 직접 라벨 |
| 부스별 최근 30분 비중 | **수평 막대** | **상태색** | 상태 인코딩. 순위 색칠 아님 |
| 부스별 최근 10/30/60분 | **소규모 다중** 스파크라인 | 카테고리 1 | CSS·SVG 직접 |

부스 막대를 상태색으로 칠하는 건 **상태 인코딩**이라 허용됩니다.
값이 클수록 진하게 칠하는 순위 색칠은 금지입니다 — 막대 길이가 이미 크기를 말하는데
색까지 같은 정보를 태우면 유일하게 남은 채널이 낭비됩니다.

### 3.2 캠페인 전후 변화

**덤벨 차트**를 씁니다. before·after 두 점을 선으로 잇고, 대상 부스만 강조합니다.

```
지역상점존   ●────────────▶●      8.9% → 29.8%
막국수체험존 ●◀────●              49.0% → 33.0%
```

before/after를 나란한 막대 두 개로 그리면 "증가했다"가 아니라 "두 개가 있다"로 읽힙니다.
덤벨은 변화의 **방향과 크기**를 하나의 획으로 보여줍니다.

표본이 20건 미만이면 차트를 그리지 않고 "데이터 부족" 상태 카드를 표시합니다.
표본이 부족한데 선을 그으면 그 선이 근거처럼 보입니다.

### 3.3 사전 진단

| 데이터 | 폼 | 비고 |
|---|---|---|
| 5개 항목 점수 / 배점 | **불릿 차트** | 실측 막대 + 배점 눈금 + 목표선 |
| 직전 진단 대비 | **덤벨** 또는 슬로프 | 5개 항목 전부, 개선·악화 모두 |
| 총점 | **스탯 타일 + 상태 배지** | 게이지 금지 |

**레이더 차트를 쓰지 않습니다.** 5축 레이더는 축 순서에 따라 면적이 바뀌어서,
같은 점수가 배치만 다르면 다르게 보입니다. 배점이 25·30·20·15·10으로 다른 항목을
같은 반지름에 놓는 것도 왜곡입니다. 불릿 차트는 "배점 대비 얼마"를 정확히 보여줍니다.

### 3.4 행사장 설계

| 데이터 | 폼 | 색 |
|---|---|---|
| 시간대별 존 밀도 | **히트맵** (행=존, 열=30분 버킷) | 순차 그린 |
| 시간대별 필요 인력 | **라인 + 기준선** | 카테고리 1 + 회색 기준선 |
| 예산 배치 | **수평 스택 막대 1개** | 카테고리 1~6 |
| 동선 병목 | **수평 막대 + 1.0 기준선** | 상태색 |

예산에 파이·도넛을 쓰지 않습니다. 존이 7개면 이미 한계고, 인접한 값의 크기 비교가
각도로는 안 됩니다. 가로 스택 막대 하나가 부분-전체와 크기 비교를 동시에 해결합니다.

인력 곡선의 **확보 인력선은 실선 하이라이트**입니다. 점선으로 그리면
격자인지 임계선인지 구분이 안 갑니다.

### 3.5 사후 리포트

| 데이터 | 폼 | 비고 |
|---|---|---|
| 시간대별 완료 | **영역 차트** | 최다 시간대만 직접 라벨 |
| 부스별 완료 순위 | **수평 막대** | 단일 색. 순위별 색칠 금지 |
| 미션별 완료 | **수평 막대** | 상위 10개 + "기타" |
| KPI 목표 대비 | **불릿 차트** | 측정 불가 지표는 목표만 표시, 막대 없음 |
| 참여자당 완료 분포 | **히스토그램** | 평균만으로는 편중이 안 보임 |

**측정 불가 KPI(목표 방문객)는 불릿 차트에 막대를 그리지 않습니다.**
목표 눈금만 표시하고 "측정하지 않음"을 명시합니다.
빈 막대를 0으로 그리면 달성률 0%로 읽힙니다.

## 4. 마크와 크롬

| 요소 | 규칙 |
|---|---|
| 막대 | 데이터 끝만 4px 라운드, 기준선 쪽은 각지게 |
| 선 | 2px, 곡선 보간 금지(실제 없는 값을 만들어냄) |
| 점 | 최소 8px, 겹치면 2px 표면색 링 |
| 인접 채움 | 2px 표면색 간격. 테두리를 그려 나누지 않음 |
| 격자 | 표면에서 한 단계 벗어난 실선 헤어라인. **점선 금지** |
| 축 | 헤어라인. 막대 차트의 값 축은 **반드시 0에서 시작** |
| 라벨 | 선택적 직접 라벨(끝점·최대값·강조 시리즈)만. 모든 점에 숫자 금지 |
| 범례 | 시리즈 2개 이상이면 항상 표시. 1개면 제목이 대신함 |
| 숫자 | `font-variant-numeric: tabular-nums` |
| 텍스트 색 | 항상 텍스트 토큰. **시리즈 색을 글자에 쓰지 않음** |

## 5. 상호작용

HTML 차트는 기본적으로 상호작용합니다. 정적 이미지로 두지 않습니다.

- **선·영역**: 십자선 + 툴팁. 툴팁에 전체 시리즈 값을 한 번에
- **막대·점·셀**: 마크별 호버 툴팁. 히트 영역은 마크보다 크게
- **필터**: 차트 위 한 줄에 모아 배치. 기간·부스·미션 순서 고정
- **필터를 걸어도 색은 바뀌지 않습니다.** 색은 부스에 붙어 있지 순위에 붙어 있지 않습니다.
  막국수 체험존이 초록이었으면 필터 후에도 초록입니다

**스탯 타일만 예외**입니다 — 그림이 없으니 호버할 것도 없습니다.

## 6. 접근성

- 시리즈 2개 이상이면 **범례가 항상** 있고, 4개 이하면 직접 라벨도 붙습니다.
  정체성이 색에만 의존하지 않습니다
- 모든 차트에 **표 보기** 토글이 있습니다. 스크린리더와 인쇄, 그리고
  "정확한 숫자가 필요한" 경우를 동시에 해결합니다
- 다크 모드는 **자동 반전이 아니라 별도 선택**입니다. 위 표의 dark 열은
  다크 표면에 대해 따로 검증한 값입니다
- 색각 이상·인쇄·강제 색상 모드를 위해 **텍스처 채움**을 옵션으로 제공합니다
  (45° / 135° 두 방향)
- 애니메이션은 `prefers-reduced-motion`을 존중합니다

## 7. 금지 목록

새 차트를 만들 때 아래에 해당하면 잘못된 것입니다.

- **이중 축** — y축 두 개를 한 그래프에. 두 축의 정렬은 임의라서 없는 상관관계를 만들어냅니다.
  → 차트 두 개, 소규모 다중, 또는 공통 기준(=100)으로 지수화
- **필터 시 재색칠** — 순위 기준으로 색을 배정
- **8개 초과 카테고리 색** — 새 색을 만들지 말고 "기타"로 접기
- **명목 범주에 값 램프** — 클수록 진하게. 막대 길이와 중복
- **무지개 순차 램프**
- **발산 중간에 색조** — 중간은 회색
- **상태색을 일반 시리즈에** (반대도 금지)
- **레이더 차트** — 배점이 다른 항목에 특히 위험
- **파이·도넛으로 근접값 비교**, 7조각 초과
- **점선 격자·축**
- **모든 점에 숫자 라벨**
- **막대 값 축이 0에서 시작하지 않음**
- **마크 테두리로 구분** — 표면색 간격을 쓸 것
- **곡선 보간(spline)** — 없는 중간값을 만들어냄
