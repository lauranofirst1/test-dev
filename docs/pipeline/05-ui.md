# 05 — UI 스펙

토큰 실제 값은 `design-tokens.css`에 있습니다. **본문에는 하드코딩 색상값을 쓰지 않고
토큰 이름으로만 참조합니다.** 아래 §5 대비 검증표는 예외입니다(계산 근거라서 실제 값이 필요).

프레임워크는 고르지 않습니다(아키텍트 몫). 여기서는 시각 계약만 정합니다.

---

## 1. 디자인 방향

세 부류가 같은 축제를 다르게 씁니다. 같은 토큰을 쓰되 **밀도를 다르게** 갑니다.

| 영역 | 성격 | 반경 | 카드 여백 | 기본 글자 |
|---|---|---|---|---|
| 기획자 | 문서에 가깝게. 읽는 화면 | `--radius-2xl` | `--space-7` | `--text-body` |
| 운영 대시보드 | 훑는 화면. 요약 먼저 | `--radius-xl` | `--space-6` | `--text-sm` |
| 부스 지급 | 한 손 조작. 버튼 크게 | `--radius-xl` | `--space-5` | `--text-body-lg` |
| 관객 모바일 | 노는 화면. 여백 넉넉히 | `--radius-lg` ~ `xl` | `--space-4` | `--text-body` |

**색의 역할**

- `--color-mint-*` = 브랜드. 선택 상태, 진행, 긍정적 강조
- `--color-lav-*` = 보너스·이벤트 전용. 보상 캠페인과 특별 상태에만
- `--color-ink` = 지금 눌러야 할 것. 화면당 **한 곳**
- `--color-state-*` = 예약됨. 여유·주의·집중·데이터부족에만. 차트 시리즈로 재사용 금지

## 2. 컴포넌트 인벤토리

### Button

| variant | 배경 | 글자 | 용도 |
|---|---|---|---|
| `primary` | `--color-ink` | `--color-ink-inverse` | 화면당 1개 |
| `secondary` | `--color-surface` + `--color-line` 테두리 | `--color-ink-soft` | 보조 |
| `mint` | `--color-mint-fill` | `--color-mint-ink` | 선택·확인 |
| `ghost` | 투명 | `--color-ink-soft` | 목록 내 액션 |
| `danger` | `--color-danger-bg` | `--color-danger` | 보관·삭제 |

상태: `default` / `hover`(밝기 −4%) / `focus`(`--shadow-focus`) / `active`(scale .98) /
`disabled`(opacity .45, `cursor: not-allowed`) / `loading`(스피너 + 라벨 유지, 폭 고정)

props: `variant` · `size`(sm/md/lg) · `loading` · `disabled` · `fullWidth` · `iconLeft`

> **loading일 때 라벨을 숨기지 않습니다.** 폭이 바뀌면 레이아웃이 튀고,
> 무엇을 누른 건지 알 수 없어집니다.

### StatusBadge

```
[■ 여유]  [▲ 주의]  [▮ 집중]  [· 데이터 부족]
```

variant: `low` / `caution` / `high` / `none`
각각 `--color-state-*` + `--color-state-*-bg`.

**색·모양·텍스트 세 겹이 항상 함께 갑니다.** 하나라도 빠지면 안 됩니다.
야외 직사광선에서 색 구분이 가장 먼저 무너지고, 색각 이상 사용자에게는
처음부터 색이 신호가 아닙니다.

props: `state` · `reason`(툴팁·보조 텍스트) · `compact`

### StatTile

`--text-stat` 숫자 + `--text-sm` 라벨 + 선택적 StatusBadge.
숫자는 `--weight-stat`(250)에 `tabular-nums`.

상태: `default` / `loading`(스켈레톤 바) / `empty`("—" 표시, 0과 구분)

> **측정하지 않은 값에 0을 쓰지 않습니다.** `empty`는 "—"입니다.
> 0으로 그리면 "0건 발생"으로 읽힙니다.

### Card

variant: `elevated`(`--shadow-sm`) / `flat`(테두리만) / `sunk`(`--color-surface-sunk`) /
`accent`(`--color-mint-wash`)

### FormField

`label` + `input` + `hint` + `error` + `unit`(명·원·대·개 접미).
필수는 `*`와 **레이블 텍스트 병기**. 색만으로 표시하지 않습니다.

상태: `default` / `focus` / `error`(`--color-danger` 테두리 + 아이콘 + 메시지) /
`disabled` / `readonly`

`aria-describedby`로 hint·error를 연결하고, `aria-invalid`를 설정합니다.

### QrDisplay / QrScanner

- `QrDisplay` — 관객 코드, 부스 QR. **클라이언트에서 렌더**합니다.
  외부 QR 이미지 API를 쓰면 참여 코드가 제3자 서버 로그에 남습니다.
- `QrScanner` — `BarcodeDetector` 우선, 미지원 시 JS 폴백.
  **수동 입력 폴백을 항상 함께** 노출합니다(카메라 권한 거부·조명 불량 대비).

상태: `idle` / `requesting`(권한 요청) / `scanning` / `denied`(수동 입력 안내) /
`unsupported` / `detected`

### OfflineQueueBadge

"대기 N건" + 마지막 동기화 시각. `aria-live="polite"`.
0건이어도 **표시를 유지**합니다 — 사라지면 큐가 있다는 개념 자체를 잊습니다.

상태: `synced` / `queued`(N건) / `syncing` / `failed`(재시도 버튼)

### StampBoard / StampTile

3×3 격자. 각 타일은 원본 이미지를 `background-position` + `background-size`로 자릅니다.
`locked`는 `grayscale(1) blur(2px) opacity(.5)`.

공개 애니메이션: `scale(1.09)` → `1`, `--duration-slow` `--ease-pop`,
이후 `--duration-reveal` 동안 강조 유지.

`aria-label`: "4번 조각, 열림" / "5번 조각, 잠김"

### RecommendationCard

상황 / 판단 근거 / 권장 행동 3단으로 **분리 표시**합니다.
하단에 `[확인함]` `[해당 없음]` `[추가 보상 설정]`.

> 문구는 지시가 아니라 확인 요청입니다.
> "…하세요"가 아니라 "**현장이 실제로 한산한지 확인해 주세요**".

### Chart

`06-charts.md`의 폼·팔레트 규칙을 따릅니다. 모든 차트에 **표 보기 토글**이 붙습니다.

## 3. 화면별 비주얼 스펙

공통 그리드: 데스크톱 `max-width 1120px`, 좌우 `--space-6`.
모바일 좌우 `--space-4`.

### SCR-1 기획자 워크스페이스
- 최근 축제 요약: `Card/accent`, 반경 `--radius-2xl`, 패딩 `--space-7`
- 목록: `repeat(auto-fit, minmax(280px, 1fr))`, gap `--space-5`
- 축제명 `--text-h3`, 지표는 `--text-stat` 축소판(32px)에 `tabular-nums`
- [보관]은 `Button/danger`이되 목록에서는 `ghost`, 확인 모달에서만 `danger`

### SCR-2 새 축제 생성
- progress 칩: `--radius-pill`, 현재 단계는 `Button/mint`
- 섹션 카드 사이 `--space-5`, 필드 사이 `--space-4`
- 하단 액션 바는 `position: sticky; bottom: 0`, 배경 `--color-surface` + 상단 `--color-line`
- 접근 코드 노출 화면: `--color-ink` 배경에 코드 `--text-display` `--font-mono`

### SCR-6 운영 대시보드
- KPI 4열 grid, gap `--space-4`. 모바일 2×2
- 추천 카드: `--color-state-*-bg` 배경, 좌측 4px 상태 스트라이프
- 부스 행: `--color-surface-sunk`, 반경 `--radius-lg`, 높이 최소 56px
- 미터 바: 높이 8px, `--radius-pill`, 채움은 `--color-state-*`
- 제한 안내 문구는 `--text-sm` `--color-ink-mute`로 **항상 표시**(접지 않음)

### SCR-9 부스 지급 화면
- 최대 폭 420px 중앙 정렬
- 카메라 뷰 4:3, `--radius-xl`
- 지급 버튼 높이 `--tap-primary`(56px), `Button/primary`, 폭 100%
- 성공 오버레이: 전체 화면 `--color-mint-fill`, 조각 번호 `--text-display`, 1.5초
- 상단 `OfflineQueueBadge` 고정

### SCR-10 관객 참여 화면
- QR 카드: `--color-ink` 배경, QR 최소 160px
- 진행 링: `conic-gradient(--color-mint-ink …)`, 지름 52px
- 보너스 배너: `--color-lav-fill` + `--color-lav-ink` (라벤더는 여기에만)
- 하단 CTA `position: sticky`, 높이 `--tap-primary`

### SCR-13 결과보고서
- 인쇄 대응: `@media print`에서 그림자 제거, 배경 흰색, 차트는 SVG 벡터
- 섹션 제목 `--text-h2`, 섹션 간 `--space-12`
- "미작성" 섹션은 `--color-surface-sunk` + `--color-ink-mute`로 **표시하되 숨기지 않음**

## 4. 모션

| 대상 | 지속 | 이징 | 비고 |
|---|---|---|---|
| 버튼 hover/active | `--duration-instant` | `--ease-out` | |
| 카드 진입 | `--duration-base` | `--ease-out` | opacity + 8px 상승 |
| 탭 전환 | `--duration-fast` | `--ease-in-out` | |
| 조각 공개 | `--duration-slow` | `--ease-pop` | scale 1.09 → 1 |
| 조각 강조 유지 | `--duration-reveal` | — | 애니메이션 아님 |
| 성공 오버레이 | 1500ms | `--ease-out` | 페이드 인·아웃 |
| 토스트 | `--duration-base` | `--ease-out` | 하단에서 상승 |

**`prefers-reduced-motion`** — 모든 transition/animation을 0.01ms로 줄입니다.
단 `--duration-reveal`은 줄이지 않습니다. 강조 표시가 즉시 사라지면
"새 조각이 열렸다"는 **정보 자체**를 놓치기 때문입니다. 움직임만 없애고 정보는 남깁니다.

- `mint-deep #3F8A6C`를 민트 칩 위 텍스트로 쓰면 **2.99:1로 미달**이었습니다.
  → `--color-mint-ink #256048`(5.32:1)로 교체
- `ink-mute #858C83`은 3.46:1이라 11~13px 캡션에 쓸 수 없었습니다.
  → `#666E64`(5.28:1)로 교체
- 다크 `state-high #D9546A`가 4.26:1이라 본문 기준 미달이었습니다.
  → `#E06A7E`(5.13:1)로 교체

**차트 팔레트**는 별도 기준(색각 분리도 ΔE, 명도 대역, 채도 하한, 표면 대비 3:1)으로
검증했습니다. 결과는 `docs/06-charts.md` §2에 있습니다.

## 6. 다크 모드 원칙

- 다크는 **반전이 아니라 별도 선택**입니다. 위 표의 값은 다크 표면에 대해 따로 계산했습니다
- `body`에 반드시 `--color-ground`를 명시합니다. 투명하면 호스트 배경을 빌려와 테마가 깨집니다
- **미디어쿼리나 `[data-theme]` 블록 안에서만 정의되는 색은 없습니다.**
  바닥 `:root`에 전체 라이트 팔레트가 있고, 두 블록은 **토큰만 재정의**합니다
- 다크에서 그림자는 더 깊고 불투명하게(라이트의 rgba .04 → .30)
